# CheckPvPAssistant v1.4.16 Release Notes

**Release Date:** October 29, 2026
**Type:** Hotfix
**Compatibility:**
- **Retail**: World of Warcraft (12.1.5)
- **MoP Classic**: Mists of Pandaria Classic (5.5.4)

---

## 🔄 Changes

### Bug Fixes
- Fixed a flood of `attempt to perform numeric conversion on a secret number value (execution tainted by 'CheckPvPAssistant')` errors when right-clicking an enemy player, for example to report them
- When the game hides a player's name from addons, as it does in some PvP and instance situations, the addon now leaves that player's right-click menu untouched instead of adding "Check PvP"
- The "Check PvP" option still appears for players whose names are available, including most enemy players
